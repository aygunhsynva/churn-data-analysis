# Customer Churn Data Analysis

This project focuses on customer churn data analysis using Python in Google Colab. The main purpose of the project is to explore customer data, analyze customer behavior, and identify possible patterns related to customer churn.

The project includes data cleaning, exploratory data analysis (EDA), and visualization processes to better understand the dataset and extract meaningful insights.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Workflow

The project includes the following stages:

1. Importing and exploring the dataset
2. Data cleaning and preprocessing
3. Handling missing or inconsistent data
4. Exploratory Data Analysis (EDA)
5. Creating visualizations and charts
6. Analyzing customer-related patterns and trends

## Project Goal

The aim of this project is to:

* gain insights from customer data,
* analyze factors related to customer churn,
* and improve practical data analysis skills using Python.

## Files

* `codestar_task_8_3_data_analysis_visualization.ipynb` — Main notebook containing the complete analysis process.

## Results

The analysis provides a better understanding of customer behavior and demonstrates how data analysis techniques can be applied to real-world business datasets.
